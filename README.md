# Макет сайта БОАР

Статический макет сайта Белорусского общества анестезиологов-реаниматологов + демо личного кабинета.

## Публичная ссылка (для показа)

https://leshahker.github.io/bsaer-mockup/

Кабинет: https://leshahker.github.io/bsaer-mockup/cabinet/  
Логин: `admin` / `admin`

## Локальный запуск (по желанию)

```bash
npm install
npm start
```

Открыть: http://localhost:3000

Локальный Express-сервер нужен только если отрабатываете настоящий серверный чат. Для показа профессору достаточно GitHub Pages — чат там демо в браузере.
